# sl-wb

一个用**纯 HTML + CSS + JavaScript**写的极简本地动态流应用：发布短动态、按时间倒序浏览、点赞。所有数据保存在浏览器 Local Storage 中，不上传任何服务器。

## 功能

- **昵称设置**：首次进入时设置昵称（可跳过为「访客」），顶栏可随时修改；新动态以当前昵称署名。
- **发布动态**：最多 280 字，实时字数环提示，内容为空时发布按钮禁用，支持 `Ctrl / ⌘ + Enter` 快捷发布。
- **查看动态**：按发布时间倒序展示，显示首字母头像、昵称、相对时间与正文；无内容时展示空状态引导。
- **点赞**：每条动态可点赞 / 取消点赞，计数与状态持久化。
- **本地持久化**：动态、点赞、昵称全部写入 Local Storage，刷新或重开浏览器后依然保留。
- **清空数据**：底部「清空本地数据」可重置（带二次确认）。

## 技术栈

- 原生 HTML / CSS / JavaScript（ES5 兼容写法，无框架、无构建、无 npm 依赖）
- Local Storage 持久化，版本化 key：`slwb.posts.v1`、`slwb.profile.v1`
- 渲染使用 `createElement` / `textContent`，从根上规避 XSS
- 深色玻璃拟态主题，响应式布局，适配 `prefers-reduced-motion`

## 运行

直接双击 `index.html` 即可使用。若想通过本地服务访问：

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 目录结构

```
sl-wb/
├── index.html   # 页面骨架：顶栏、发布区、动态列表、昵称弹窗、toast
├── styles.css   # 深色玻璃质感主题、动画与响应式
├── app.js       # 数据存取、渲染、发布 / 点赞 / 昵称 / 清空
└── README.md
```

## 数据说明

数据仅存于当前浏览器的 Local Storage：

| Key | 内容 |
| --- | --- |
| `slwb.posts.v1` | 动态数组（id、作者、内容、时间戳、点赞数、是否已点赞） |
| `slwb.profile.v1` | 当前昵称 |

清除浏览器站点数据或点击页面底部「清空本地数据」即可删除。
